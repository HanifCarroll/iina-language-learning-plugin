## Native playback controls: Top layout workaround (2026-09-24)

Tested on macOS 27.0 / IINA 1.5.0-beta2 with Neden's installed 0.1.12 candidate and the owner's open episode. **PASS, owner-confirmed:** after selecting **Video → Show Video Panel → Layout → Top**, the owner could click the top Play button with Neden active. The accessibility tree showed Neden's overlay and advancing subtitle text. Top remains selected. This is a workaround, not a fix for floating/bottom controls.

Earlier isolation checks failed with Neden's overlay hidden; the owner confirmed Play worked after fully disabling Neden and restarting IINA. Those results supersede any broad claim that overlay click-through guarantees native OSC button access. IINA's full-window overlay container and view ordering are the leading source-supported explanation; the native click recipient was not instrumented.

The automated mouse test was inconclusive: captures intermittently showed overlapping title/control bars or blank frames, and fullscreen coordinate clicks returned `noWindowsAvailable`. Fullscreen was entered and exited, but fullscreen button operation was not verified. Other toolbar buttons, volume, repeated Play/Pause, and other window sizes remain unverified. No AI request was made during this check.

## Always-stacked secondary and overlay switch (version 0.1.10 candidate)

The separate **Show secondary subtitle above source** setting is gone. With a usable selected source and any selected secondary track, Neden owns both native subtitle visibility states and renders the secondary text directly above the source, including during a source-cue gap. If the source cannot be matched safely or the secondary track is Off, it restores native secondary rendering. A legacy saved `showTranslation: false` value is ignored. Appearance retains independent size, color, bottom-distance, and inter-line gap controls.

**Selectable subtitle overlay** is now a stateful switch under **Subtitles → Overlay control**. Turning it off calls the existing safe-shutdown path: cancel active work, reject late output, clear the conversation, resume eligible playback, and restore subtitle state owned by that window. Turning it on reclaims the overlay. DOM tests verify the switch bridge actions; session tests verify subtitle visibility through cue gaps, mismatch, Off, and disable. The earlier native active-stream Disable Overlay check used the same shutdown path, but the new switch has not been exercised in installed IINA.

`bun run release:check` passed **64/64** Bun tests with **424 assertions**, TypeScript checking, Swift compilation, archive integrity, and **10/10** controlled helper tests. The 0.1.10 archive is in ignored `dist/`. An initial package-picker attempt hit ScreenCaptureKit error `-3812`. Opening the same archive from Finder instead brought up IINA's existing `file-system` and `video-overlay` permission warning; **Install** completed. IINA listed **Neden 0.1.10**, and installed `Info.json`, `main.js`, `ui/sidebar.html`, and `ui/sidebar.js` hashes matched the package. A cold restart reopened the owner's *Leyla ile Mecnun* movie and loaded Neden.

In the restarted IINA 1.5.0-beta2, the sidebar listed Turkish source track #3 and English secondary track #1. Its accessibility tree showed both the English and Turkish overlay text nodes, the **Selectable subtitle overlay** switch on, and appearance controls without the former stacking checkbox. Screen capture returned a blank frame during this check, so exact visual position, spacing, and duplicate native rendering were not confirmed by pixels. The switch was not toggled and no new AI selection was intentionally made as part of the install check. The player state changed during the final inspection, so no final playback position or pause state is asserted.

## Appearance preview and cue replay (version 0.1.9)

Appearance changes now preview in the overlay without writing preferences. Apply saves them; leaving Subtitles or native sidebar dismissal restores the saved appearance and any native secondary visibility temporarily owned by the preview. Saving AI settings does not commit an appearance draft. The sidebar keeps draft inputs stable when streamed chat state updates.

Replay line uses the captured source cue and current subtitle delay/speed, plays it once, and returns to the previous position and pause state without sending an AI request. Stop replay and Hide/Resume return early. User seeks, source-track or media changes, and a different player window do not receive a return seek. The implementation distinguishes the initial programmatic seek from a user seek using the observed position and a short time window; native event ordering still needs checking in installed IINA.

## Current limits and recovery

IINA installed the plugin into an already open movie window in the normal profile at 21:37, after that window's `iina.window-loaded` event. Version 0.1.0 waited for the missed event and showed an empty sidebar tab. IINA source confirms a newly enabled plugin instance is added to existing players without replaying that event. Fully quitting and reopening IINA is the immediate recovery. Version 0.1.1 checks `core.window.loaded`, initializes that existing window once, and has an automated test for both late install and duplicate event delivery. Native hot-install of 0.1.1 remains unverified.

The tested IINA release has no plugin teardown callback on raw Preferences disable. Turn off the in-plugin **Selectable subtitle overlay** switch for safe shutdown. If raw disable hides source text, use **Subtitles → Show Subtitles**; if it hides secondary text, use **Subtitles → Show Secondary Subtitles**; if a conversation left playback paused, use **Playback → Resume**. The helper may continue to its total timeout and an external provider may bill for work already sent. Quit IINA disconnected the tested helper and cleaned its FIFO, but forced host crashes and exact cancellation latency are not guaranteed.

The plugin intentionally requires user-supplied external UTF-8 SRT/VTT for selectable source subtitles. Full-length files are supported within the documented 8 MiB/50,000-cue limits; complete commercial tracks are valid runtime input but never included as fixtures. Embedded, bitmap, or unreadable tracks keep IINA's native playback usable. A trusted controlled HTTPS endpoint check and independent Turkish-language review remain outstanding. The source repository is public, but this version has not been released.
